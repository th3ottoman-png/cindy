## Caveats
- The model also ran one `terminal` call (229 chars) before `read_sheet`; its content was not recorded, so the correct answer alone does not prove the tool path. The
  `read_sheet completed` line plus the bridge `mcp session initialized` do.
- Single session, single turn. Overlap of two live full-access sessions (distinct identities through two gateways) is not live-tested.
- Session close (home + gateway removal) and `auth.json` refresh write-back were not exercised live.
- Hermes' gateway `argv` shows its code lives under `~/.hermes/hermes-agent/` (the install the `~/.hermes-cindy` home links to via `installs`); Cindy read or wrote nothing in `~/.hermes`.
- A separate daily-driver `hermes gateway` from `~/.hermes` was already running; untouched.
