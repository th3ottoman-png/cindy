proves the allowlist gate itself allowed both.

## 6. Defect found live and fixed red-first

After removing the block, `routing.yaml` was one byte short: the final trailing newline had
been dropped. `applyWorkersBlock` was absorbing the last element of `split('\n')` as if it
were a blank separator line, when it actually represents the file's terminating newline.
A red test (`removing an appended block restores a file ending in one newline byte for byte`)
was added first, then the condition was narrowed to `to + 1 < lines.length - 1`.
After the fix, a live write → remove round-trip through real IPC left `routing.yaml`
`cmp`-identical to the backup. Pure suite: 35 tests green.
