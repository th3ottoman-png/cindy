## 7. Bugs found and fixed during the proof (same commit)

1. **Wire shape:** the composer sends `{text, images, files, …}` and the coordinator drains
   `{type:'user', content: string | blocks[]}`, not plain strings. The service now rewrites all
   three shapes, keeping attachments.
2. **Send boundary:** the modern send path is the input coordinator drain through the shared
   `sendToAgentAccepted` wrapper, not the legacy `maker:send` handler alone. The interception
   lives in the shared wrapper (covers both).
3. **Excerpt re-trigger:** a join prompt whose excerpt quotes an earlier `@agent:` token was
   re-entering the flow on the worker and failing with WORKER_CANNOT_NEST. Orca-origin
   (`persistUserMessage.origin.kind === 'orca'`) and auto-resume sends now pass through
   untouched. (The first worker's dispatch was lost to this bug before the fix; the clean
   cycle above is post-fix.)
