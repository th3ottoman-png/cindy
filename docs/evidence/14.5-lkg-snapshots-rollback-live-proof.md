## 1. Implementation summary

- **`packages/maker-core/src/doctor/snapshots.ts`** (exported via `packages/maker-core/src/doctor/index.ts`):
  - `createLkgSnapshot(ctx, { reason, report, packs })`: collects only config-layer files under `~/.cindy-harness/` (`providers.yaml`, `routing.yaml`, `guardrails.yaml`, `web-budget.yaml`, `housekeeping.json`, `plugins.json`, `security.json`, `vault.json`, `*-sessions.json`, `experts/<slug>/{expert.md,tools.yaml}`) and `~/.hermes-cindy/config.yaml` (guarded by `assertNotDailyHermes`), writes byte-exact copies + `versions.json` + SHA-256 `manifest.json` into staging `.tmp-*` then atomically renames to `~/.cindy-harness/doctor/lkg/<UTC stamp>/`.
  - Strict exclusion filter (`isExcludedSnapshotRelPath`) + `lstat` non-symlink guard: excludes `.env`, `.env.*`, `auth.json`, `*.key`, `*token*`, `*credential*`, `*secret*`, `*.db*`, `*.sqlite*`, `session-homes/`, `cache/`, `installs/`, and `logs/`, and never follows symlinks.
  - Retention (`pruneLkgSnapshots`, configured via `~/.cindy-harness/doctor/doctor.yaml`): keeps the newest `lkg_keep` (default `20`) plus everything younger than `lkg_min_days` (default `14`), ignoring non-stamp directories and never following symlinks.
  - `diffAgainstLatestLkg(ctx)` + `config.lkg-diff` check in `packages/maker-core/src/doctor/packs/config.ts`: verifies snapshot copies against `manifest.json` SHA-256 and compares live config-layer files (`ok` when no snapshot exists or matching; `warn` naming changed/added/removed files when diverged).
  - `planLkgRollback(ctx, opts)` + `rollbackLkgSnapshot(ctx, opts)`: verifies SHA-256 & byte lengths before modifying any live file; enforces Cindy app closed (`ctx.appRunning` or shared `detectAppRunningState(ctx)`) whenever `hermes/config.yaml` is among restored files; moves each replaced file aside to `<file>.pre-rollback-<stamp>` and atomically renames a sibling temp file into place; re-runs the `config` layer checks.
- **`scripts/cindy-doctor.mjs`**: added subcommands `snapshot [--reason <text>]`, `snapshots`, and `rollback <stamp> [--file <rel>] [--yes]` (with interactive `Apply? [y/N]` confirmation when `--yes` is not supplied).
