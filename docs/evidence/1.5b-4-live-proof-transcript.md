Date: 2026-10-29. Hermes Agent v0.22.5 (2026.9.24). Model: `deepseek-flash` via DeepSeek (one paid chat turn).

## Setup (what was real, what was a harness)

- Real: `hermes-cindy` binary and `~/.hermes-cindy` (config, DeepSeek credentials untouched), the built shim
  `packages/cindy-tools/dist/hermes-bridge-shim.mjs`, the production `createHermesBridgePreparer`, the real local HTTP
  bridge, the real `cindy_docs` provider (tool `read_sheet`).
- Harness: the bridge was hosted by a throwaway vitest-run script (not committed), **not** by the running desktop app.
  So `maker-host/index.ts` injection and the UI path are NOT covered by this proof (see ROADMAP 1.5b-4b).
- `~/.hermes-cindy/config.yaml` backed up to `config.yaml.bak-20261029` first; the shim entry was added by the preparer through the
  1.5a config writers and removed afterwards; the file is byte-identical to the backup after the run.
