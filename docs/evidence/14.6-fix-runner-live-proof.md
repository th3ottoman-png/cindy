## 1. What shipped

- **Fix runner (`packages/maker-core/src/doctor/fix-runner.ts`, re-exported via `packages/maker-core/src/doctor/index.ts`):**
  - Enforces the 7-step blueprint §5 invariant across every `DoctorFix`:
    1. `previewFix(registry, ctx, fixId, { target })` returns a `FixPlan` with zero filesystem or process side effects.
    2. `runFix(...)` requires explicit confirmation (`yes: true` or `confirm(plan)` returning `true`); defaults to cancelling with zero mutations.
    3. Refuses before any write if `(fix.needsAppClosed || plan.requiresAppClosed)` and Cindy is running.
    4. Captures a `pre-fix:<fixId>` LKG snapshot plus pre-fix regular-file state for `moves-files` fixes (and recorded targets for `kills-process`).
    5. Runs `fix.apply(ctx, plan)` with atomic writes.
    6. Re-runs `fix.recheck` checks via `runChecks`; any remaining `fail` or thrown/diverged failure automatically rolls back from step 4 and sets `rolledBack: true`.
    7. Appends one redacted JSON line `{ at, fixId, target, ok, rolledBack, recheckCounts }` to `~/.cindy-harness/doctor/fix-log.jsonl`.
- **Three initial fixes registered alongside their checks:**
  - `fix.config.restore-lkg` in `packages/maker-core/src/doctor/packs/config.ts` (plus `fixIds: ['fix.config.restore-lkg']` attached to failing config checks and `config.lkg-diff` warnings): validates candidate non-`pre-fix:` LKG snapshots using a purely in-memory read-only overlay `DoctorFs` (zero disk writes during `preview`), skips newer broken snapshots to pick the newest passing copy, restores via `rollbackLkgSnapshot` (`fileRels` subset when `--target` is omitted so untouched `hermes/config.yaml` is not disturbed during running-app UI harness fixes, while refusing `hermes/config.yaml` restores unless Cindy is closed).
  - `fix.proc.kill-orphans` in `packages/maker-core/src/doctor/packs/processes.ts`: extracts shared `detectOrphanProcesses(ctx)` (normalizing macOS `/private/var` / `/private/tmp` `session-homes/` realpaths and checking non-system `ppid === 1` processes), re-verifies every planned PID at `apply` time so any PID that stopped being orphaned or newly appeared is skipped untouched, sends `SIGTERM`, polls up to `3000` ms (`orphanGraceMs` test seam), and escalates survivors to `SIGKILL`.
  - `fix.proc.stale-socket` in `packages/maker-core/src/doctor/packs/processes.ts`: `needsAppClosed: true`, fixes `probeDaemonSocket` to preserve `socketConnected = true` when a socket accepts TCP/Unix connections even on RPC timeout so active sockets are never misclassified as stale, refuses live or symlink sockets at both `preview` and `apply`, and renames stale sockets aside to `<socket>.stale-<stamp>`.
- **`snapshots.ts` updates:** `diffAgainstLatestLkg` ignores `pre-fix:*` rollback snapshots when selecting the baseline LKG snapshot, and `rollbackLkgSnapshot` accepts `fileRels` + `skipRecheck` for `fix-runner` composition.
- **CLI subcommand (`scripts/cindy-doctor.mjs`):** added `pnpm run doctor fix <fixId> [--target <x>] [--yes]` with `Apply? [y/N]` interactive confirmation when `--yes` is omitted (refusing non-TTY without `--yes`), app-closed guard, human and `--json` output.
