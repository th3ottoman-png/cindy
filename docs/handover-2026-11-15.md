## 6. Traps learned this session (save hours)

- **ECC `stop:format-typecheck` hook = formatter churn.** At the end of every agent turn it runs
  Prettier over each JS/TS file touched by the **Edit/Write tools**. Most upstream files are not
  Prettier-clean, so a 5-line edit becomes a 1 000-line reformat diff (it happened to `MessageStream.tsx`
  and `SettingsView.tsx` in 13.4). **Edit existing files with a script** (Python exact-anchor
  replacement, each anchor asserted to occur once, atomic temp + rename); the hook does not track shell
  edits. New files are fine to write with Write. Before every commit, compare
  `git diff --stat` with `git diff -w --stat`.
- **GateGuard (`Fact-Forcing Gate`) blocks the first Write/Edit of each file** and some Bash commands.
  State what it asks for: call sites (after a Grep/`git grep` that covers the file), schemas, rollback
  for destructive commands, and **the user's verbatim instruction**. Then retry the same call.
- **macOS paths are case-insensitive.** `Foo.tsx` next to `foo.ts` makes `import './Foo'` resolve to
  `foo.ts` (`.ts` is tried first); React then reports "Element type is invalid … got: undefined". Give
  pure helpers a different base name (`webBudgetChipText.ts`).
- **Full-access hooks read credentials from a file, not the env.** The hook command carries
  `--credentials <session home>/auto-review.json`; only Auto turns get the socket/token env. In daemon
  tests, call `runAutoReviewHook({ …, credentialsFile })` for non-Auto sessions.
- **Default mode runs `--safe-mode`, which ignores config and hooks.** Anything enforced in the hook
  only covers Full access and Auto.
- **Hermes 0.23 can wrap tool calls** in a meta tool `tool_call` (`{calls:[{name,arguments}]}`),
  mostly for lazily loaded MCP tools; built-ins like `web_search` arrived direct.
- **Parallel tool calls are real.** The model sent four `web_search` calls in one batch; any per-session
  counter must reserve before awaiting and release on block.
- The 1.14 daemon session id is `cindy-<cindySessionId>`. The helper is exported as
  `@cindy/maker-core/hermes-daemon-session-id`; use it when main must talk to the daemon about a Cindy
  session.
- `test:unit:related` prints very long command lines; grep for `^PASS` / `^FAIL` to read the result.
