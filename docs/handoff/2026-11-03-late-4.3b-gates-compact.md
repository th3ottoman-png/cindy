## Design decisions (settled, do not reopen)

- Lizi rows: id/name = **plugin id** (`lizi/docs`), source from every **non-essential** builtin
  with a `PLUGIN_ID_TO_MCP_ID` mapping (android, browser, computer, slack, ssh, contacts, docs,
  collab — 8 rows; memory/xdt_helper/scheduler/lsp are essential = infrastructure, excluded).
  Lizi toggle = `registry.setEnabled(id, enabled)` user-default scope, applies to NEW sessions
  (hint line says so). Hermes toggle = `setHermesMcpServer(name, {...server, disabled: !enabled})`.
- Health policy: list computes static only (stdio = local fs executable check, http = `unchecked`,
  in-process enabled = `ok`). The probe runs ONLY on explicit per-row Check (no unprompted
  outbound, AGENTS §3). Probed http health is cached per id in the host; toggle drops the cache.
- IPC mirrors 4.2b: assertTrusted sender on all 3 channels, broadcast `changed` after
  set-enabled AND check-health; renderer refetches on changed.
